# Симулятор пандуса — ДБН В.2.2-40:2018 (Зміни № 3, № 4)

**Відкрити:** https://oleksandrtymoshenkowork-dev.github.io/pandus-simulator/

Інтерактивна перевірка пандуса за нормою інклюзивності: повзунки й точний ввід (ухил можна вписати як `1:15`), миттєвий вердикт із пунктами ДБН і кнопками «виправити», схеми в реальному масштабі — профіль, поперечний переріз (рис. 5а, 5д), план — з анімованим кріслом колісним.
Кнопка **«Поділитися»** дає посилання з усіма параметрами — колега відкриє той самий пандус.

## Що перевіряється
- ухил ≤ 8 % (п. 5.3.1), **табл. Д.1** — підйом маршу залежно від ухилу (обов'язкова для нового будівництва, рекомендована для реконструкції), автоматична розбивка на марші;
- підйом маршу ≤ 0,80 м і площадки ≥ 1,50 м (п. 5.3.1.2); ширина 1,20 / 1,80 м, для існуючих будівель 0,90 м (п. 5.3.1.1);
- поперечний ухил 1–2 % (п. 5.1.5); поручні з обох боків на 0,90 і 0,70 м, дитячий 0,50 м (п. 5.3.2), Ø 35–45 мм і продовження 0,30 м (п. 5.3.2.1), крайні опори за 0,15–0,20 м від заокруглення (п. 5.3.2.3), контрастні поручні (п. 5.3.2.2);
- бортики ≥ 0,05 м (п. 5.3.2.3), шорстке покриття й виділені площадки (п. 5.3.2.4, 5.1.7), заборона накладних планок і тактильних смуг на пандусі (п. 5.3.1.3).

## Структура
```
index.html, styles.css
js/norms.js     нормативне ядро (чисті функції, табл. Д.1, стан у посиланні)
js/views.js     SVG-схеми; js/anim.js — анімація; js/ui.js — елементи керування; js/app.js — застосунок
js/vendor/      htm + Preact (13 КБ, без збірки й CDN)
tests/          node --test tests/
```
Локально: `python -m http.server 8765` → http://localhost:8765. Тести запускаються й перед кожним деплоєм на Pages.
